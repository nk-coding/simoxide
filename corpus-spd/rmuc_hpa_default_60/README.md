# RMUC HPA Default-60

Origin: RMUC mosaic demonstrator, Slingshot experiment `hpa-default-target-60`.
Active policies are CPU utilisation HPA at 61%/59% on DeviceCommunication and
DataProcessing (cooldown 180 s). DataProvider time policies and `scaleOutTwice` are
inactive. Flattened for simoxide (root `.spd` / `.semanticspd`, `run.json`).
