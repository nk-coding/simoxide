# History

Records of how SimOxide and its QVTo engine were built. They describe the project at the time
they were written and are not kept up to date; the current documentation is the site in `docs/`
(see the top-level README).

| File | Contents |
|---|---|
| `worklog.md` | the development log: one section per work package (scope, what was verified, what was open) |
| `plan.md` | the original plan, scope and conventions the work started from |
| `performance-log.md` | the performance work round by round: measurements before and after, profiles, rejected ideas |
| `qvto-plan.md` | the QVTo engine's milestone log (Q0-Q7, SPD-Q1, SPD-Q2) with the exit criteria as met, from when it was the separate repository qvto-rs |
| `qvto-simoxide-integration.md` | qvto-rs's plan for running the engine inside SimOxide through an adapter (superseded by the merge, `crates/qvto/docs/merge-into-simoxide.md`) |
