# Model corpus

`corpus/` holds the models that SimOxide is compared with the reference on. Each directory holds
the PCM model files (flat, relative hrefs), a `run.json` with the seed, stop conditions and
network flags ([Output formats §5](../guide/formats.md#_5-run-configuration-run-json)), and
`expected/` with the reference's `trace.jsonl`, `tape.jsonl` and `measurements.csv` (files over
256 KiB are stored gzipped).

- **`h*`: hand-made models**, one feature each: schedulers and ties, workloads, branches, loops,
  collection iterators, forks and double resumes, passive resources, composition, parameters,
  infrastructure and resource calls, linking resources, distributions, triggers, middleware,
  nested containers, recursion. They are generated by `reference/refsim gen corpus`
  (`reference/src/refsim/corpus/HandMade.java`); `FEATURES.txt` describes each one.
- **`x_*`: example models** from the Palladio repositories, imported by
  `reference/import-external.sh` from the list `reference/external-models.txt`, which also records
  the models that were skipped and why. Sources: Palladio-Example-Models (`x_pem_*`), SimuLizar
  tests and examples (`x_sl_*`), Slingshot end-to-end tests (`x_ss_*`) and the espresso example.
  They get the refsim default monitors (`refsim.monitorrepository`: FeedThrough response times,
  active and passive resource metrics); their own monitors are not used. Their licences are
  listed in `LICENSES`.

Further model directories:

| Path | Contents |
|---|---|
| `corpus-fuzz/` | saved fuzzing cases: minimised divergences (all fixed), reference aborts with the reference's partial outputs, regression cases |
| `crates/simoxide-sim/tests/models/` | corpus variants with sliding-window monitors (`w_*`), trigger variants (`t_*`), example models with their own monitor repositories (`u_*`) |
| `crates/simoxide-sim/tests/models-replay/` | fuzz regressions checked in tape-replay mode |
| `crates/simoxide-cli/bench/models/` | benchmark-only models |

Maintenance:

```sh
reference/regen-expected.sh            # regenerate corpus/*/expected and corpus/INDEX.md
reference/regen-expected.sh --check    # expected outputs are current
reference/verify-determinism.sh        # two fresh JVMs, 3x repeat in one JVM, equal to expected/
```
