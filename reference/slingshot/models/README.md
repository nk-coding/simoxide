# Models of the Slingshot reference runner

| Directory | Source | Changes |
|---|---|---|
| `spd_minimal` | `Palladio-Documentation-Slingshot/examples/minimalexample` (commit `9444815`, 2024-09-13) | only the files the example's `default.experiments` uses as initial model; `default.slo` dropped (the SLO metamodel is not installed), `representations.aird`, `default.dlim`, `default.usageevolution`, `default.experiments` not copied |
| `probes/*` | generated by `tools/probegen.py` | probe models of the Slingshot semantics (`docs/spec/slingshot/`); `probe.json` (time, seed, rules), `expected/` (det outputs, `probes.sh`) |
| `spd_time_policies` | `spd_minimal` | P1 decision-log model: seven time-triggered policies on the elastic infrastructure (`>=`, `<=`, `==`, `>`), cooldown (25 s, max 1), interval constraints (once and repeated), a thrashing constraint (15 s) and a group-size constraint (1-3) on the target group, an absolute and a relative adjustment, an inactive policy; `expected/` = det outputs (`-simTime 100 -seed 1`) |
| `x2/ss_q37_*` | `probes/ss_link` | X2 cases of quirk Q37 for `corpus-ss/`: the link connects only one of the two containers (`ss_q37_fallback`) or does not exist (`ss_q37_none`) |
| `spd_scale_in` | `spd_minimal` | S0 probe of quirk Q5: second policy "Scale in at 80" (`StepAdjustment -1` at t = 80); the accounting demand raised from 2.0 to 9.0 so that several jobs are on `AppServer_1` when it is removed |
